Información sobre mi relato y este sitio.

Un relato personal

Escribí gran parte de este relato durante mi tratamiento para el cáncer testicular, iniciado en diciembre de 2004. Refleja lo que sabía, sentía y comprendía entonces. Desde entonces han cambiado algunos tratamientos, recomendaciones médicas y sitios web.

El contenido sirve como información y reflexión personal. No sustituye el consejo de un médico u otro profesional sanitario cualificado. Si te preocupa tu salud, busca asesoramiento profesional adecuado.

Fotografías, pruebas de imagen y pies

Las fotografías e imágenes médicas proceden de mi propia experiencia. Algunas muestran tratamientos, heridas quirúrgicas u otros aspectos de la atención hospitalaria.

Traducciones

Escribí el diario en inglés. Las versiones traducidas de este sitio web se prepararon con la ayuda de GPT. Las traducciones pueden contener errores, especialmente en la terminología médica. El texto en inglés sigue siendo el relato original.

Privacidad y preferencias de lectura

Este sitio usa Cloudflare Web Analytics para ayudarme a comprender las visitas y el rendimiento de las páginas. Cloudflare lo describe como un servicio que prioriza la privacidad y no sigue a las personas entre sitios. Las preferencias de lectura se guardan por separado en tu dispositivo para recordar tus opciones la próxima vez.

El proveedor que aloja este sitio puede registrar información técnica, incluidas direcciones IP, por seguridad y funcionamiento. Su política de privacidad explica cómo la trata.Declaración de privacidad de GitHub para conocer cómo trata la información.
